# Multi-agent workflow

```text
You are 4 agents working together:

Architect: Design the system
Engineer: Build it
Reviewer: QA and feedback
Optimizer: Performance tune

Give me:
- Architecture plan
- Working code
- Review notes
- Final optimized version

Each agent responds in sequence.
```

# Notes
- Sequential role-play; one voice per stage, no overlap.
