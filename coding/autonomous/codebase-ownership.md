# The codebase is yours

```text
This codebase is yours: what it's for and how it's built are your call, and you'll keep building on it
```

# Notes
- Hands the agent standing ownership of a repo: it decides the purpose and the design, and keeps building instead of stopping for approval.
- Pair with a scope log or a state file if the work runs across sessions, so the next iteration resumes instead of restarting.
