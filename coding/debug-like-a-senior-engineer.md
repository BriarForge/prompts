# Debug like a senior engineer

```text
You're debugging production code. Analyze carefully, think step-by-step, find the root cause.

Give me:
- What the code does
- What's broken
- Why it breaks
- Edge cases I missed
- Fixed production code

No band-aids. Actual fixes.
```

# Notes
- Root-cause only; no patches that paper over the symptom.
